# Movie Recommendation System

## Objective

Develop a recommendation system that suggests movies based on user preferences using Content-Based Filtering.

## Features

- Movie recommendations
- Content-based filtering
- Cosine similarity
- User-friendly interface

## Technologies Used

- Python
- Pandas
- Scikit-Learn

## Dataset

A sample movie dataset containing movie titles and genres.

## How to Run

```bash
python recommendation.py
```

## Example

Input:

Avengers

Output:

Iron Man
Captain America
Black Panther
Hulk
Thor
