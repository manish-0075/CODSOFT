# Rule-Based Chatbot

## Objective
This project is a simple Rule-Based Chatbot developed using Python.

The chatbot responds to user inputs based on predefined rules using if-elif-else statements.

## Features

- Greets users
- Answers basic questions
- Provides help information
- Handles unknown inputs
- Allows users to exit the chat

## Technologies Used

- Python 3

## How to Run

1. Install Python.
2. Download the project files.
3. Open terminal in the project folder.
4. Run:

```bash
python chatbot.py
```

## Sample Interaction

You: hello

Bot: Hello! How can I help you today?

You: what is your name

Bot: My name is CODSOFT AI ChatBot.

You: bye

Bot: Goodbye! Have a nice day.
